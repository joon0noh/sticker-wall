# 스티커 담벼락

21명의 학생이 색 닉네임으로 방학 이야기를 포스트잇에 쓰고, 궁금한 이야기에 익명 질문을 남기는 GitHub Pages용 교실 활동입니다.

## 준비 순서

1. Firebase Console에서 웹 앱을 만들고 **Authentication**의 `익명` 및 `이메일/비밀번호` 로그인을 활성화합니다.
2. **Realtime Database**를 만들고, `database.rules.json` 내용을 규칙 탭에 붙여 넣어 게시합니다.
3. `firebase-config.example.js`를 복사해 `firebase-config.js`로 이름을 바꾸고 Firebase 웹 설정값을 넣습니다.
4. 이 폴더를 GitHub 저장소에 올린 뒤 Pages의 배포 원본을 기본 브랜치의 루트로 지정합니다.
5. 교사는 영문·숫자로 된 추측하기 어려운 방 이름을 정하고, 예를 들어 `?room=summer-5a-8q4m2z9k`를 사이트 주소 끝에 붙여 학생에게 QR 코드나 링크로 안내합니다. 방 이름이 없는 기본 주소는 활동을 열지 않습니다.

## 교실 진행

1. 교사는 페이지에서 `교사 로그인`을 누르고 Firebase 이메일/비밀번호 계정으로 로그인합니다.
2. `작성 시작`을 누릅니다. 학생은 출석 번호와 고유한 색을 선택한 뒤, 최대 3개의 포스트잇을 작성합니다.
3. `전체 공개·질문 시작`을 누릅니다. 모든 포스트잇은 노란 공용 색으로 보이며, 학생은 내용만 보고 최대 5개의 익명 질문을 남깁니다.
4. `질문 정지·발표 시작` 뒤 질문이 많은 순서로 포스트잇을 선택합니다. 선택된 포스트잇만 학생 고유 색으로 바뀌며 발표가 시작됩니다.
5. 필요하면 `출석 번호 보이기`를 켭니다. 이 정보는 교사 화면에서만 사용하며 기본값은 꺼짐입니다.

## 개인정보 주의

- 학생에게 실제 이름을 입력시키지 않습니다.
- 출석 번호 대응표는 `teacherRecords` 경로에 별도 저장됩니다.
- 교사는 활동이 끝난 뒤 Firebase Console에서 해당 활동 데이터와 익명 계정을 정리할 수 있습니다.
- 화면에 보이는 포스트잇과 질문은 교사가 검토하고, 부적절한 내용은 Firebase Console에서 삭제할 수 있습니다.
